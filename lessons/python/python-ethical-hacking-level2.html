2️⃣ Banner Grabbing (Service Identification)

Why Banner Grabbing?

It helps identify services, versions, and misconfigurations. 


import socket

target = "127.0.0.1"
port = 80

s = socket.socket()
s.settimeout(3)
s.connect((target, port))
s.send(b"HEAD / HTTP/1.1\r\n\r\n")
banner = s.recv(1024)
print(banner.decode())
s.close()

3️⃣ TCP Port Range Scanner


import socket

target = "127.0.0.1"

for port in range(1, 1025):
    s = socket.socket()
    s.settimeout(0.5)
    result = s.connect_ex((target, port))
    if result == 0:
        print("Open port:", port)
    s.close()
Scan only localhost or lab machines.

4️⃣ Password Attack Theory (Educational)

Dictionary Attack Concept


passwords = ["admin", "123456", "password", "letmein"]
correct_password = "admin"

for guess in passwords:
    if guess == correct_password:
        print("Password found:", guess)
        break
Used only to test your own login systems.

5️⃣ Web Pentesting Basics (Safe)

Check HTTP Headers


import requests

url = "https://example.com"
response = requests.get(url)

for header in response.headers:
    print(header, ":", response.headers[header])

Security Headers to Look For

  • Content-Security-Policy
  • X-Frame-Options
  • X-XSS-Protection

7️⃣ Defense: Secure Coding

Password Hash + Salt


import bcrypt

password = b"mypassword"
hashed = bcrypt.hashpw(password, bcrypt.gensalt())
print(hashed)

Verify Password


bcrypt.checkpw(b"mypassword", hashed)
