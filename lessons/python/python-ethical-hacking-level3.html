2️⃣ Brute Force Simulation (CTF-Style)

Password Guess Script


password_list = ["1234", "admin", "admin123", "password"]

correct = "admin123"

for pwd in password_list:
    print("Trying:", pwd)
    if pwd == correct:
        print("✔ Password Found:", pwd)
        break
CTF teaches logic — not crime.

3️⃣ Command Injection Concept (Local Lab)

Vulnerable Code


import os

command = input("Enter command: ")
os.system(command)

Why Dangerous?

User controls system commands.

Secure Version


import subprocess

subprocess.run(["ls"])

4️⃣ File Upload Vulnerability (Theory)

Dangerous Pattern


file = request.files["file"]
file.save(file.filename)

Secure Fix


if file.filename.endswith(".jpg"):
    file.save("uploads/image.jpg")
