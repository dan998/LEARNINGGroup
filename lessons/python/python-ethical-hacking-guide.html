2️⃣ Networking Fundamentals

Understanding IP & Ports

An IP address identifies a device. Ports identify services (HTTP = 80, HTTPS = 443).

Get IP Address Using Python


import socket

hostname = socket.gethostname()
ip = socket.gethostbyname(hostname)
print("Your IP:", ip)

4️⃣ Port Scanning (Educational)

Simple Port Scanner


import socket

target = "127.0.0.1"
ports = [21, 22, 80, 443]

for port in ports:
    s = socket.socket()
    s.settimeout(1)
    result = s.connect_ex((target, port))
    if result == 0:
        print("Port open:", port)
    s.close()
⚠️ Scan only your own systems or lab environments.

5️⃣ Password Security & Hashing

Why Hash Passwords?

Passwords should never be stored in plain text.

Hashing Example


import hashlib

password = "mypassword"
hashed = hashlib.sha256(password.encode()).hexdigest()
print(hashed)
